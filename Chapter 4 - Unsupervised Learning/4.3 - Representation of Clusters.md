- Use the centroid of each cluster to represent the [[Cluster]]
	- Compute radius and std dev to determine the spread in each dimension
	- centroid rep works well if the clusters are hyper-spherical
	- elongated or other shaped clusters, centroids are not sufficient

- ## Using a classification model
	- all data points in a cluster have the same class label
		- We can run a supervised learning algo (e.g. [[decision tree]]) on the data to find a classification model, and we can get rules for our data
		  
- ## Use frequent values to represent clusters
	- We cannot use a classification model if we have a text document, for example
	- Main method in text clustering, where a small set of frequent words in each cluster is used to represent the cluster
	  
- ## Arbitrary shaped clusters
	- difficult to represent
	- Centroids not suitable for natural clusters not hyper-elliptical or hyper-spherical
	- Not many applications for this
