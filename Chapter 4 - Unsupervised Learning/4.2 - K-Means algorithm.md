- One of the most popular / best known algorithms
- [[partial clustering]] algorithm
- Given:
	- Set of data points $D$
		- $\{x_1, x_2, ..., x_n\}$
		- where $x_i=(x_{i1}, x_{i2}, ..., x_{in}$ is a vector in a real valued space, and $r$ is the number of attributes / dimensions in the data
- Algorithm partitions the given data into $k$ clusters
	- Each cluster has a center, called a **centroid**
	- $k$ is user-specified, we cannot find $k$ automatically, basically impossible in high-dimensional space.
	- But also, there's no point to finding $k$ automatically because the quality of the result depends on the application.
	- We try different $k$s to see which ones make sense in our application
- Algorithm:
	- 1) Randomly select $k$ data points (seeds) to be the initial centroids
	- 2) Assign each data point to the closest centroid
	- 3) Recompute the centroids using the current cluster memberships
	- 4) If a convergence criterion is not met, go to 2)
	- What is the complexity of the algorithm?
		- It's a linear algorithm, we normally assume $k$ is very small, so the complexity is based on the # of data points, we tend to converge from 30 to 50 iterations in practice
- Stopping/convergence criterion
	- 1) No / minimum reassignments of data points to different clusters
	- 2) no / minimum change of centroids
	- 3) minimum decrease in the sum of squared error [[SSE]]$$SSE=\sum_{j=1}^{k}\sum_{x\in C_j}{dist(x,m_j)^2}$$

- Disk version of k-means
	- Can be implemented with data on disk,
	- scan data once per iteration, centroids can be computed incrementally
	- We must control number of iterations, in practice <50
- It does not scale up very well, there are better scale-up algorithms, (ex: [[BIRCH]])
- Strengths of k-means
	- Simple, easy to understand & implement
	- Linear time complexity
	- Most popular clustering algorithm
- Weaknesses
	- Terminates at a local optimum if SSE is used, global optimum is hard to find due to complexity
		- e.g. same data may give different results depending on the seeds that are chosen
	- Only applicable if the mean is defined
		- categorical data, k-mode - centroid is represented by most frequent values
	- User needs to specify $k$
	- sensitive to outliers
	- How do we deal with outliers?
		- We can remove data points that are much further away from other data points
		- We can also use random sampling to select data points since the chance of selecting an outlier is very small
	- Algorithm is sensitive to **initial seeds**
		- Usually issues occur when the initial centroids are too close to each other,
			- so we can use distance to select centroids
	- k-mean is also not suitable for discovering clusters that are not hyper-ellipsoids or hyper-spheres![[Pasted image 20260302101132.png]]
		- Why is it not useful to find irregular cluster shapes? We cannot describe what our cluster looks like, makes it very difficult to evaluate
	- Summary
		- Still most popular clustering algorithm despite its weaknesses
		- No clear evidence that other clustering algos perform better
		- comparing different clustering algos is a difficult task - no one knows which cluster is better!
