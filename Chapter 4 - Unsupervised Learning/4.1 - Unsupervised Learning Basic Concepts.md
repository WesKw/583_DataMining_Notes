- It's very hard to objectively evaluate unsupervised learning models
	- This is because we don't have a target or correct solution
- Recall:
	- [[Supervised]] Learning learns models or classifiers from the data that relate data attributes to a target attribute
		- Goal is to be able to predict a class given a set of attributes
	- [[Unsupervised]] Learning uses data that has no target class / attribute
		- Want to find intrinsic structures in the data
		  
- ## [[Cluster]]ing
	- One main approach to unsupervised learning
	- Finds similarity groups in data (Clusters)
		- Group data instances that are similar / near to each other in one cluster and data that is different from each other 
	- Clustering is considered synonymous w/ unsupervised learning, but [[Association Rule Mining]] is also considered unsupervised learning
	- What is clustering for?
		- Ex: Want to organize a collection of text documents according to content similarities
	- **Clustering is one of the most utilized data mining techniques**
	- Text clustering is important for online documents, for example
	  
	- ### Aspects of clustering
		- [[Partitional clustering]]
		- [[4.4 - Hierarchical Clustering]]
		- A [[distance function]]
		- [[Clustering quality]]
			- Inter-clusters maximized / minimized
		- Quality of a clustering depends on the algorithm, distance function, and application
		- Clustering is very subjective!
