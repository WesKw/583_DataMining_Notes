- [[Text classification]] - learning classification models from training documents w/ pre-defined class labels
- We can apply previous classifiers and [[3.6 - Naive Bayesian Classification]] to text classification
	- However, they are not very effective
- In early days, language models couldn't take off because the amount of data was too small
- originally, statistical language models
- **In a language model, we are not sure of the actual distribution of data**
## Probabilistic framework
- [[Generative model]]: Each document is generated by a parametric distribution governed by a set of hidden parameters
	- Model makes 2 assumptions:
		- **1) data / documents are generated by a [[Mixture Model]]**
		- **2) There is a one-to-one correspondence between mixture components and document classes**
- **Note that here we do not consider sequence - this is different to LLMs where sequence is considered.**
## [[Mixture Model]]
- mixture model: models data w/ a number of statistical distributions
	- Each distribution corresponds to a data cluster/class
	- parameters of the distribution provide a description of the corresponding cluster
- summation of multiple distributions
- each class is generated by a separate generator
	- ex: we have 3 classes C1, C2, and C3. Each class has a generator behind it. **We cannot mix classes together into 1 generator! - this is a problem discussed later**
		- The idea behind this is that common words in one class may be completely uncommon in another - eventually everything might have the same very low probability or almost 0 chance to appear at all.
- Each distribution in a mixture model is called a **mixture component**
- The distribution / component can be of any kind
- Ex: 
	- we have a sample probability density function of a 1d data set
		- classes generated by a mixture of 2 normal distributions
		- One per class, parameters are the mean and the standard deviation
		  ![[Pasted image 20260301150329.png]]
			- **Probability density function** of a 1d data set w/ 2 classes
			- Parameters are denoted by $\theta_j$ are the mean $\micro_j$, standard deviation $\sigma_j$
			- $\theta_i = (\micro_i, \sigma_i)$
- Let # of mixture components in a mixture model be $K$
- Let $j$th distribution have params $\theta_j$
- Let $\Theta$ be the set of parameters of all components: $\Theta = \{\phi_1, \phi_2, ..., \phi_k, \theta_1, \theta_2, ..., \theta_k\}$
- $\phi_j$ is the **mixture weight/probability** of mixture component $j$ and $\theta_j$ is the parameters of component $j$
- How does the model generate documents?
	- How do we pick the generator with no prior data? We use probability to sample a generator, then use the generator to generate data points
	- We estimate the probabilities in order to build a generator when we are given data

## Document generation
- **Mixture weights** are _class prior probabilities_ (recall [[3.6 - Naive Bayesian Classification]]). a.k.a $\phi_j = Pr(c_j|\Theta)$
- Mixture models generate a document $d_i$ by:
	- 1) First, select a mixture component / class according to class prior probabilities (mixture weights), $\phi_j = Pr(c_j|\Theta)$
	- 2) Second, have this selected mixture component ($c_j$) generate a document $(d_i)$ according to its parameters, w/ distribution $Pr(d_i|c_j;\Theta)$, or $Pr(d_i|c_j;\Theta_j)$
		- What is the probability of document $d_i$ given class $c_j$ and the set of parameters $\Theta$?
		- We can say$$
		  Pr(d_i | \Theta)=\sum_{j=1}^{|C|}{Pr(c_j | \Theta) Pr(d_i | c_j;\Theta)}$$
## Model text documents
- NB classification treats a document as a bag of words (e.g. frequency is important, sequence does not matter). We assume:
	- 1) Words of a document are generated independently of context given the class label
		- We use NB assumption as previously specified ([[conditional independence]] given a class $c_j$)
	- 2) Probability of a word is independent of its position in the document
			- document length is chosen independent of its class
## [[Multinomial Distribution]]
- W/ our assumptions, each doc can be regarded as generated by a **multinomial distribution**
- Generalized binomial distribution
- Multinomial trial: a process resulting $k >= 2$ outcomes w/ probability $p_1, p_2,..., p_k$
	- Ex: rolling dice is a multinomial trial, fair dice w/ 6 faces has $p_1 = p_2 = ... = p_6 = 1/6$
- Let $X_i$ be the # of trials resulted in $i_{th}$ outcome 
- Collection of random variables $X_1, X_2, ..., X_k$ has the multinomial distribution w/ parameters n, $p_1, p_2, ..., p_k$, where $n$ is the total number of trials

## Multinomial distribution of documents
- Each document is drawn from the multinomial distribution of vocabulary w/ as many independent trials as the length of the document $d_i$, e.g. $(|d_i| = n)$
- Outcomes are the words from a given vocabulary $V = \{w_1, w_2, ..., w_{|V|}\}$
- Probability of each word is computed from the training data of each class $Pr(w_i|c_j)$
- Imagine we have a dice with $V$ faces
	- To generate a document for class $c_j$, we roll the dice $|d_i|$ times and record the words that appear.

## Use probability function of multinomial distribution
$$Pr(d_i|c_j;\Theta) = Pr(|d_i|)|d_i|!\prod_{t=1}^{|V|}{\frac{Pr(w_t|c_j;\Theta)}{N_{ti}!}}$$
- where $Pr(w_t|c_j;\Theta)$ is the probability a word shows up given a class
- $N_{ti}$ is the number of times that word $w_t$ appears in $d_i$$$\begin{matrix}
  \sum_{t=1}^{|V|}{N_{it}=|d_i|}\\
  \sum_{t=1}^{|V|}{Pr(w_t | c_j;\Theta)=1}
  \end{matrix}$$
## Parameter estimation / training
- Parameters are estimated based on empirical counts
- We smooth the probability w/ lidstone smoothing, $0 \le \lambda \le 1$ for handling 0 counts for infrequent occurring words that do not appear in the training set, but may show up in the test set
	- __This is probably on the midterm apply the equation for a probability__
$$\begin{matrix}
Pr(w_t | c_j ; \Theta) = \frac{\sum_{i=1}^{|D|}{N_{ti}*Pr(c_j|d_i)}}{\sum_{s=1}^{|V|}{\sum_{i=1}^{|D|}{N_{si}*Pr(c_j|d_i)}}}\\
\\\text{When using lidstone smoothing:}\\
Pr(w_t | c_j ; \Theta) = \frac{\lambda + \sum_{i=1}^{|D|}{N_{ti}*Pr(c_j|d_i)}}{\lambda|V|+\sum_{s=1}^{|V|}{\sum_{i=1}^{|D|}{N_{si}*Pr(c_j|d_i)}}}
\end{matrix}$$
- Ex: If we're given a set of documents $d1, ..., d_k$, at training time we use probability smoothing 
- Class prior probabilities, which are mixture weights, can be estimated using the training data$$
	Pr(c_j|\Theta)=\frac{\sum_{i=1}^{|D|}Pr(c_j|d_i)}{|D|}
	$$

  \end{matrix}$$

  * If the final classifier classifies each document in a single class, then the class w/ the maximum posterior probability is selected
    $\text{arg max}_{c_j\in C}Pr(c_j|d_i;\Theta)$
## Discussion
- Most assumptions made by NB learning are violated in practice, however NB learning still produces accurate models
- NB learning is good for *topic*-based classification
- Main problem is mixture model assumption (we assume that each class is associated with its own generator)
	- violation of this assumption results in poor classification performance
	- this assumption has a problem: there are many applications that say we're only interested in certain classes - every class has a bunch of words that indicate that class
		- When we lump classes together, the probability of choosing certain words becomes very small even if they're common among specific documents. (we add more words to the pool which decreases the probability of picking a specific word)
- NB learning is very **efficient** - it's functionally just counting
- NB learning is very easy to implement - **but we have to be careful of multiplication - to avoid overflow take the log**
