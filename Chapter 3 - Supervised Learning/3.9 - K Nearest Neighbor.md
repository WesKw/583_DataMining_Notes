- k-Nearest Neighbor Classification ([[kNN]])
- Advantages
	- simplicity
	- Linear classification time in training set size for each test case
	- Deals with complex and arbitrary decision boundaries
	- Classification and accuracy is strong and tends to be as accurate as other methods
	- slow at classification time
	- no understandable model
- For a test instance $t$ define $k$-neighborhood $B$ as $k$ nearest neighbors of $t$
	- Count $n_j$ of training classes in $B$ that belong to class $c_j$
	- Estimate $Pr(c_j|t)$ as $n_j/k$
- kNN does not build a model
- kNN algorithm
	- 1. Compute distance between test instance t and every example in D
	- 2. Choose k examples in D that are nearest to t, $B \subset D$
	- 3. Assign t the class that is the most frequent class in B
- Basically, we look at the $k$ nearest neighbors, and assign a probability of a class given the majority classes of the neighbors.
- $k$ is chosen via a [[validation set]] or [[Cross validation]] by trying many k values
- [[distance function]] depends on applications, may need to try many functions and pre-processing methods
- Lazy, stores data set and performs computations at time of classification
