- With supervised learning, we need to make some type of decision
- Examples:
	- Whether or not to put a patient into an intensive care unit
		- predicting high-risk patients from low risk patients
	- Whether or not someone is approved for a house or credit card loan
- With examples we are trying to classify applications or people
- __Supervised machine learning__ - the task of learning a target function that can be used to predict values of a discrete class attribute
	- Also called, classification, or inductive learning
	- Data is a set of data records (instances/cases) described by a set of
		- __$k$ attributes__ $A_1,A_2,...,A_k$
		- __One class attribute:__ a set of predefined class labels
		- Each record has a class label
	- Goal: Learn a __classification model__ that can be used to predict future cases
		- Example: given a set of previous loan training data, can we predict if a person will be approved for a loan given a set of attributes
- What is the difference between supervised and unsupervised learning?
	- [[Supervised]] 
		- Classification is supervised learning from examples
		- data is labeled with pre-defined classes
		- wants to be able to **predict future classes** given data
	- [[Unsupervised]]
		- Class labels are not given
		- Wants to **establish existences of classes** or clusters in data
- Supervised learning process:
	- 1) Learn a model with given training data
	- 2) Test the model with __unseen__ test data to assess accuracy
		- $\text{Accuracy}=\frac{\text{Number of correct classifications}}{\text{Total number of test cases}}$
- What is [[learning]]?
	- Data set $D$
	- task $T$
	- Performance measure $M$
	- Learn $D$ to perform $T$, improvements measured by $M$
	- Goal is to perform $T$ better compared to without learning
- When we say "No learning":
	- We mean classifying all future applications to the majority class in the data
- __Learning assumes that data is independent and identically distributed (i.i.d)__
- Leaning assumes that data is split into *training* and *test* data
	- Distribution of training and test examples should be the same (this includes future examples)
	- Training should be sufficiently representative of the test data
	- Often this assumption is violated in practice
