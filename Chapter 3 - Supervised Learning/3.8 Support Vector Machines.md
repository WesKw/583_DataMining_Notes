	- __Support Vector Machines__- linear classifiers that find a hyperplane to separate two classes of data
		- Kernel functions used for nonlinear separations
			- Kernel functions expand the space of attributes (ex, go from 10 attributes to 10,000)
		- Performs a classification more accurately than other classic models -> good for high dimensional data
		- Best text classifier before deep learning
		- If we have many classes we can find a hyperplane for one against the rest
		- Mathematically difficult to follow
		- Let the set of training examples *D* be
		- $\{(x_1, y_1), (x_2, y_2), ..., (x_r, y_r)\}$
		- Where $x_i = (x_1, x_2, ..., x_r)$ is an input vector in the set of reals, y and $y_i$ is its class label, either -1 or 1.
		- 1: positive class, -1: negative class
		- SVM finds a linear function of the form: (w: weight vector)
	$$
	f(x) = <w * x> + b\
	y_i = ...
	$$
		* The hyperplane separates positive and negative training data is $<w*x> + b = 0$
		* Also called the __decision boundary (surface)__
		* There are many hyperplanes, how do we choose the best one?
			* __Maximal margin hyperplane__ - we don't just want to choose the line in the middle, there's too many in the middle. We want to find the hyperplane with the largest boundary
				* The maximal margin hyperplane minimizes the error bound
	* Linear SVM
		* Assumes the data are linearly separable
		* Consider a positive data point $(x^+, 1)$ and a negative data point $(x^-, 1)$
		* We define 2 parallel planes that separately pass through $x^+$ and $x^-$, $H_+$ and $H_-$
		* They are also parallel to $<w * x>+b = 0$
		* Then we can compute the margin between 2 planes (which is the distance between 2 hyperplanes)
		* use distance formula from linear algebra
		* $\frac{|<w*x_i>+b|}{||w||}$
		* margin$= d_+ + d_- = \frac{2}{||w||}$
	* Optimization problem
		* Given a set of linearly separable training examples D
			* Learning is to solve the constrained optimization problem: $\frac{<w*w>}{2}$, subject to the piecewise function for y ($y_i(<w*x_i>+b)\ge 1), i=1,2,...,r$
	* Lagrangian Method
		$$L_p = \frac{1}{2}<w*w> - \sum_{i=1}^{r}{\alpha_i[y_i(<w*x_i>+b)-1)]}
		$$
	* $\alpha_i$ are lagrange multipliers
	* Optimal solutions must satisfy certain conditions (Kuhn-Tucker conditions) necessary but not sufficient
		* Important for constrained optimization
	* Complemetary condition shows only those data points on the margin hyperplanes can have $\alpha_i>0$ since for them $y_i(<w*x_i>+b) - 1 = 0$
		* these points are called the __support vectors__ (they have data points who have $\alpha_i>0$)
		* These points make the SVM solvable - the only useful points are the points that are on the hyperplanes
* Solve the problem
	* Kuhn-Tucker conditions are necessary for an optimal solution but not efficient
	* But for a minimization problem w/ a convex obj function and linear constraints, Kuhn-Tucker conds are __necessary and sufficient__
	* Solving the problem is still difficult due to inequality constraints

	* Go from primal to a dual - set to zero the partial derivatives w/ rspt to the primal variables then sub back into the lagrangian
* Dual optimization problem
	 * Wolfe Dual
* The final decision boundary
	* $<w*x> + b = \sum_{i\in sv}{y_i\alpha_i<x_i*x_i>+b=0}$
	* In practical SVM only the alpha is produced
	* Given a test instance z:
	* $sign(<w*z>+b)=sign(\sum_{i\in sv}{a_iy_i<x_i*z>+b})$
	* Returns 1 -> z is classed as positive, negative otherwise
	* SVM produces 2 things: alphas and support vectors
	* If we can define some kind of distance between 2 data points - then we can classify it
		* If we can provide the kernel matrix then we don't care what the type of data is
* Linear SVM: Non-separable case
	* Linear separable case is the ideal situation
	* Real-life data has noise and errors
	* If the data is noisy then the constraints will not be satisfied -> no solution
	* To allow for errors in data - we relax the margin constraints by introducing slack variables so that they are not strictly 1 or -1
* Penalizing errors in the objective function
	* "don't cross too much"
	* We assume there is some sort of noisy data points
	* We allow the hyperplanes to cross a little bit
	* Penalize the errors in the objective function by assigning an extra cost for errors
	* minimize: $\frac{<w*w>}{2} + C(\sum_{i=1}^{r}{e_i})^k$ where $e$ is the slack variable for point i
* New Optimization Problem:
	* Soft-margin SVM - SVM with the relaxed constraints
	* Now we have lagrange multipliers for the slack variables and the data points
