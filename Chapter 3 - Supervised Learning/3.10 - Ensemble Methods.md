
- Can we combine multiple classifiers to produce a better classifier?
- We discuss 3 algorithms
	- [[Bagging]]
	- [[Boosting]]
	- [[Random Forest]]
- Bagging
	- Bootstrap Aggregating
	- Application of bootstrap sampling
		- Given a set $D$ w/ $m$ training examples
		- Create a sample $S[l]$ of $D$ by drawing m examples at random w/ replacement from $D$
			- [[replacement]] - some data may be repeated or left out
		- $S[l]$ of size $m$: expected to leave out 37% of examples from $D$ $(1 - 1/e)$
	- Training
		- Create $k$ bootstrap samples
		- Build distinct classifier from each $S[l]$ to produce $k$ classifiers
	- Testing
		- Classify each new instance by voting of the $k$ classifiers
	- When is bagging useful?
		- unstable learners
			- small changes in the data set cause large changes in the classifier
				- true for decision trees, neural networks
				- false for k-nearest neighbor, naive bayesian, class association rules
		- May degrade results for stable learners
- Boosting
	- Training
		- Produce a sequence of classifiers (all using same base learner)
		- classifiers are dependent on the previous one, focus on previous errors
		- examples incorrectly predicted in previous classifiers given higher weights
	- Testing
		- The results of the series of classifiers are combined to determine the final class of a test case
	- [[AdaBoost]]
	  ![[Pasted image 20260303124141.png]]
		- Weighted training set, all training data is given non-negative weights (init $w_i = 1/n$)
		- Then we build a "weaker" classifier h_t whose accuracy on the training set is 1/2
		- If we can't get better than random then we stop
		- Performance of boosting depends on data and base learner
			- Base learner must be as unstable as bagging
		- Susceptible to noise
			- Large outliers can hurt performance
- Random Forest
	- Based on [[decision tree]]s, most effective general classification ensemble
	- Random trees come from sampling a subset of attributes at each node
	- For all training sets
		  draw a boostrap sample $S[i]$ of $D$ similar to bagging
		  build a random-forest tree w/ $S[i]$
			  for a node $j$, sample random subset of attributes $A_i$ at remaining node
			  Then select the best attribute from $k$ attributes to split the tree
	- Testing: Voting like bagging
