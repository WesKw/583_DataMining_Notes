	- __[[Support Vector Machine]]s__- linear classifiers that find a hyperplane to separate two classes of data
		- [[Kernel function]]s used for nonlinear separations
			- Kernel functions expand the space of attributes (ex, go from 10 attributes to 10,000)
		- Performs a classification more accurately than other classic models -> **good for high dimensional data**
		- Best text classifier before deep learning
		- If we have many classes we can find a hyperplane for one against the rest
		- Mathematically can be difficult to follow
		- Given:
			- Set of training examples $D$ = $\{(x_1, y_1), (x_2, y_2), ..., (x_r, y_r)\}$
			- $x_i = (x_1, x_2, ..., x_r)$ is an input vector in a real valued space, $y_i$ is its class label, either -1 or 1.
		- 1: positive class, -1: negative class
		- SVM finds a linear function of the form$$\begin{matrix}
	f(x) = \langle w * x \rangle + b\\
	y_i = \begin{cases}
	1 \text{ if } \langle w *x_i \rangle + b \ge 0\\
	2 \text{ if } \langle w*x_i \rangle +b \lt 0
	\end{cases}\end{matrix}$$
			- Where $w$ is the weight vector.
		* The [[hyperplane]] separates positive and negative training data is $<w*x> + b = 0$
		* Also called the __decision boundary (surface)__![[Pasted image 20260302140716.png]]
			* Each line is an example of a hyperplane
		* There are many hyperplanes, how do we choose the best one?
			* __Maximal margin hyperplane__ - we don't just want to choose the line in the middle, there's too many in the middle. We want to find the hyperplane with the largest boundary
				* The maximal margin hyperplane minimizes the error bound![[Pasted image 20260302141525.png]]
				* Want to maximize the margin between the data points $x^+\text{ and }x^-$  
				  
	* # Linear SVM
		* Assumes the data are linearly separable
		* Consider a positive data point $(x^+, 1)$ and a negative data point $(x^-, 1)$
		* We define 2 parallel planes that separately pass through $x^+$ and $x^-$, $H_+$ and $H_-$
		* They are also parallel to $<w * x>+b = 0$ -> this is the hyperplane through the middle
		* Then we can compute the margin between 2 planes (which is the distance between 2 hyperplanes)
		* use distance formula from linear algebra $\frac{|<w*x_i>+b|}{||w||}$
		* margin$= d_+ + d_- = \frac{2}{||w||}$
	* Optimization problem
		* Given a set of linearly separable training examples $D$
			* Learning is to solve the constrained optimization problem: $\frac{<w*w>}{2}$, subject to the piecewise function for y ($y_i(<w*x_i>+b)\ge 1), i=1,2,...,r$
	* Lagrangian Method$$L_p = \frac{1}{2}<w*w> - \sum_{i=1}^{r}{\alpha_i[y_i(<w*x_i>+b)-1)]}$$
	* $\alpha_i$ are lagrange multipliers
	* Optimal solutions must satisfy certain conditions (Kuhn-Tucker conditions) necessary but not sufficient
		* Important for constrained optimization
	* Complemetary condition shows only those data points on the margin hyperplanes can have $\alpha_i>0$ since for them $y_i(<w*x_i>+b) - 1 = 0$
		* these points are called the __support vectors__ (they have data points who have $\alpha_i>0$)
		* These points make the SVM solvable - the only useful points are the points that are on the hyperplanes
* Solve the problem
	* Kuhn-Tucker conditions are necessary for an optimal solution but not efficient
	* But for a minimization problem w/ a convex obj function and linear constraints, Kuhn-Tucker conds are __necessary and sufficient__
	* Solving the problem is still difficult due to inequality constraints
* PRIMAL TO DUAL AHHHHHHHHHHHH
	* Go from primal to a dual - set to zero the partial derivatives w/ rspt to the primal variables then sub back into the lagrangian
* Dual optimization problem
	 * Wolfe Dual
* The final decision boundary
	* $<w*x> + b = \sum_{i\in sv}{y_i\alpha_i<x_i*x_i>+b=0}$
	* In practical SVM only the alpha is produced
	* Given a test instance z:
	* $sign(<w*z>+b)=sign(\sum_{i\in sv}{a_iy_i<x_i*z>+b})$
	* Returns 1 -> z is classed as positive, negative otherwise
	* SVM produces 2 things: alphas and support vectors
	* If we can define some kind of distance between 2 data points - then we can classify it
		* If we can provide the kernel matrix then we don't care what the type of data is
* Linear SVM: Non-separable case
	* Linear separable case is the ideal situation
	* Real-life data has noise and errors
	* If the data is noisy then the constraints will not be satisfied -> no solution
	* To allow for errors in data - we relax the margin constraints by introducing slack variables so that they are not strictly 1 or -1
* Penalizing errors in the objective function
	* "don't cross too much"
	* We assume there is some sort of noisy data points
	* We allow the hyperplanes to cross a little bit
	* Penalize the errors in the objective function by assigning an extra cost for errors
	* minimize: $\frac{<w*w>}{2} + C(\sum_{i=1}^{r}{e_i})^k$ where $e$ is the slack variable for point i
* New Optimization Problem:
	* __Soft-margin SVM__ - SVM with the relaxed constraints
	* Now we have lagrange multipliers for the slack variables and the data points

- Last time: we looked at how Support Vector Machines are designed
- Talked about linear separable and linear non-separable cases of SVMs
	- Positive data on one side of a margin hyperplane, and negative data on the other size
	- Non-separable case allows the data to have some kind of noise

- Important property of SVM 
	- Solution is sparse in $\alpha_i$ Many training data points are outside the margin are and their $\alpha_i$'s in the solution are zero
	- Data points on the margin ($y(<w*x_i>)+b=1$), which are support vectors in the separable case - inside the margin or errors are non-zero
		- Why - because the distance is measure from the hyperplanes - not the center
	- Without the sparsity property - SVM would not be practical for large data sets
- So what does SVM actually output?
	- It produces $\alpha$ and support vectors (data points where $\alpha$ is not equal to 0)
	- The classification essentially just tries to compute distance
		- Because of this, the SVM can actually classify anything
- How to deal with nonlinear separation?
	- SVM requires linear separation
	- Real-life datasets aren't always linear
	- To deal with nonlinear separation, the same formulation and techniques are used as for the linear case
	- Transform the input data to another space (usually a higher dimension)
		- linear decision boundary can separate the + and - examples in the space
	- __Feature space__ - transformed data space
	- __Input space__ - the original data space
- Space transformation 
	- Map the data in the input space $X$ to a feature space $F$., then $(x_i, y_i)$ becomes $\theta(x_i, y_i)$
	- We don't change the SVM formulation at all, we just use the new feature space
- Example
	- Suppose we input space is 2D, and we map from 2D to 3D:
		- $(x_1, x_2) -> (x_1^2, x_2^2, \sqrt{2}x_1x_2$
		- Ex: ((2, 3), -1) -> ((4, 9, 8.5), -1)
- Problem w/ explicit transformation
	- Suffers from curse of dimensionality
	- Huge # of features - even with useful transformations w/ reasonable amts of attributes
		- this makes it computationally infeasible
	- But we don't need explicit transformations!
- Kernel Functions
	- In the dual formulation both the construction of the optimal hyperplane and evaluation of the corresponding decision function only require dot products, and never the mapped vector in its explicit form
		- So, if we can compute $<\phi(x) * \phi(z)>$ using the input vectors, we don't need to know the feature vectors!
	- We can compute the dot product in SVM by using Kernel functions, denoted by K
		- $K(x,z) = \langle\phi(x) * \phi(z)\rangle$
	- Example:
		- Polynomial kernel: $K(x,z) = \langle x * z\rangle^d$
			- Do a proof by computing the kernel w/ degree 2 in a 2d space
			- So $\langle x * z\rangle^2$ is a dot product in a transformed feature space
		- Remember in real life we don't actually do this tee hee
- Kernel trick
	- We don't need to find the mapping function
	- We can just apply the kernel function by replacing all the dot products w/ the kernel function
	- We can't just apply this to anything, we need to prove that the kernel function is a dot product of some feature space
	- [[Mercer's Theorem]] proves that a kernel function is a dot product in some feature space
- Common kernel functions
	- The dot product is also a kernel w/ a feature map being the identity function
	- Polynomial: $K(x,z)=(\langle x*z\rangle+\theta)^d$
	- Gaussian RBF: $K(x,z)=e^{-||x-z||^2/2\sigma}$
	- Sigmoidal: $K(x,z)=tanh(k\langle x*z\rangle - \delta$
	- where $\theta\in R$, ....
- Other SVM issues
	- Only works in real-valued spaces - must convert categorical values to numeric values
		- Cannot deal with missing values 
	- Only does 2 (binary) classification 
		- for multiclass problems, some strategies
			- 1 against rest, one against one, etc
	- Hyperplane produced by SVM is hard to understand by people
		- Commonly used in applications that don't require human understanding
