- Probabilistic view: Supervised learning can be seen as computing probability $Pr(c | d)$
- Let A<sub>1</sub> through A<sub>k</sub> be attributes w/ discrete values, class C
	- Given test ex d w/ attribute values a<sub>1</sub> - a<sub>k</sub> , classification is basically computing posterior probability
		- $Pr(C = c_j | A_1 = a_1,..., A_{|A|} = a_{|A|})$
	- **Can we estimate the probability directly (eg without using a decision tree or list of rules)?**
		- **No** - In order for a probability to be reliable, we need to have a large set of data or a model!

- Bayes' Rule
	- $c_j$ is the maximum a posteriori (MAP) hypothesis
- $$
	Pr(C = c_j | A_1 = a_1,..., A_{|A|} = a_{|A|})\
	= \frac{Pr(A_1 = a_1,..., A_{|A|} = a_{|A|} | C = c_j)Pr(C=c_j)}{Pr(A_1 = a_1,..., A_{|A|} = a_{|A|})}
	  $$
	  - $Pr(C=c_j)$ is the class prior probability - easy to compute from training data
		  - it's the fraction of data in D with class $c_j$
- Computing Probabilities
	- Denominator is irrelevant if we don't need a probability output but a decision (same for every class)
	- We only need $P(A_1 = a_1, ..., A_k = a_k | C=c_j)$ 
		- Which we can recursively write using mathematics (please look at the slides)
		- So we need to assume that all attributes are conditionally independent given the class $C = c_j$ (given a class, all attributes have nothing to do with each other)
	- Eventually, we land on  $\prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_j)}$ 
	- Then our final naive bayesian classifier:
	- $\frac{Pr(C = c_j) \prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_j)}}{\sum_{r=1}^{|C|}{Pr(C = c_r)}\prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_r)}}$
		- If we only need a decision on the most probable class for each test instance, then we only need the numerator since the denominator is the same for all classes.
		- So 
		$$
		c=arg_{c_j} max\ Pr(C=c_j)\prod_{i=1}^{|A|}{Pr(A_i = a_i | C =c_j)}
				 $$
		- gives us the most probable class for a test case
	- We need to compute prior probabilities $Pr(C = c_j)$ and $Pr(A_i = a_i | C = c_j)$
		- $Pr(C=c_j) = \frac{number\ of\ examples\ of\ class\ c_j}{total\ examples\ in\ the\ data\ set}$
		- $Pr(A=a_i | C=c_j) = \frac{number\ of\ examples\ with\ A_i=a_i\ and\ class\ c_j}{number\ of\ examples\ of\ class\ c_j}$
- Classify test instance
	- If we only need the most probable class for the test then the denominator doesn't matter
	- we can take the max of $Pr(c_j)$

- Additional issues
	- Zero counts - an attribute value never occurs with a class in the training set, but shows up in testing, so we need (**smoothing**)
		- for every possible value, we have a small probability $\lambda$ 
			- Usually, we set to 1
		- 
	- Numeric attributes
		- Naive Bayesian classifiers assume all attributes are categorical
		- Must be discretized
			- 2 strategies
				- 1) Don't care - chop into equal size bins
				- 2) We use entropy (:agony:)
		- We can use decision tree induction
	- Missing values: ignored
		- We can ignore this because we compute probabilities for every attribute
- Advantages of NB classifiers:
	- Easy implementation
	- very efficient
	- good results in many applications
- Disadvantages of NB classifiers
	- Assumes class conditional independence
		- significant loss of accuracy when this assumption is violated
		- e.g. in a game dataset (tic tac toe), decision tree and CBA gives 100% accuracy while NB only gives 70% (the game is deterministic, real datasets are not going to be deterministic)
