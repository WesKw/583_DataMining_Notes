- Supervised learning can be seen through a probabilistic ([[probability]]) lens: 
	- Estimating a class posterior probabilities given a test example $d$ is 
	  $Pr(C=c_j | d)$
	- Then we can use this method to see what class $c_j$ is more probable
- [[Bayesian Classification]]
  
- Setup:
	- Let $A_1, A_2, ..., A_{|A|}$ be the set of attributes w/ discrete values from data set $D$
	- Class attribute is $C$
	- Given test ex $d$ w/ attribute values $a_1, ..., a_{|A|}$ , classification computing posterior probability
		- $Pr(C = c_j | A_1 = a_1,..., A_{|A|} = a_{|A|})$
		- The predicted class is class $c_j$ such that the above probability is maximized
	- **Can we estimate the probability directly (e.g. without using a [[decision tree]] or list of [[rule]]s)?**
		- **No** - In order for a probability to be reliable, we need to have a large set of data or a model!

- Bayes' Rule
	- $c_j$ is the maximum a posteriori (MAP) hypothesis
	  $$\begin{matrix}
		Pr(C = c_j | A_1 = a_1,..., A_{|A|} = a_{|A|})\\
		= \frac{Pr(A_1 = a_1,..., A_{|A|} = a_{|A|} | C = c_j)Pr(C=c_j)}{Pr(A_1 = a_1,..., A_{|A|} = a_{|A|})}\\
		= \frac{Pr(A_1=a_1,...,A_{|A|}=a_{|A|} | C=c_j)Pr(C=c_j)}{\sum_{r=1}^{|C|}{Pr(A_1 = a_1, ..., A_{|A|}=a_{|A|} | C = c_r)Pr(C=c_r)}}
		\end{matrix}$$
	* Recall [[conditional probability]] formula:
		* $P(A|B) = \frac{Pr(B|A)*P(A)}{Pr(B)}$
		* The probability of $A$ conditioned on $B$ is equal to the probability of $B$ conditioned on $A$ times the probability of $A$ over the probability of $B$
	* $Pr(C=c_j)$: class prior probability
		* Compute by finding the fraction of data in $D$ with class $c_j$
	- Denominator is irrelevant if we don't need a **probability output**, but a **decision** (same for every class)
	- We only need $P(A_1 = a_1, ..., A_{|A|} = a_{|A|} | C=c_i)$ 
		- Which we can recursively write using MATH
	$$\begin{matrix}
	P(A_1, ..., A_{|A|} | C=c_i)\\
	= Pr(A=a_1 | A_2=a_2,...,A_{|A|}=a_{|A|}, C=c_j)*Pr(A_2,...,A_{|A|}=a_{|A|} | C=c_j)
	\end{matrix}$$
		- We can rewrite the second factor recursively too.
		- From hereon, we need to assume [[conditional independence]]
		- Assume that all attributes are conditionally independent given the class $C = c_j$
			- AKA: we can reduce the previous equation to:
			  $P(A_1 = a_1, ..., A_{|A|} = a_{|A|} | C=c_i) = Pr(A_1 = a_1 | C=c_j)$
	- Eventually, we land on  $\prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_j)}$ 
	- Then our final naive Bayesian classifier:$$\frac{Pr(C = c_j) \prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_j)}}{\sum_{r=1}^{|C|}{Pr(C = c_r)}\prod_{i=1}^{|A|}{Pr(A_i = a_i | C = c_r)}}$$
		- **This is the conditional probability formula again**
		- If we only need a decision on the most probable class for each test instance, then we only need the numerator since the denominator is the same for all classes.$$
		c=arg_{c_j} max\ Pr(C=c_j)\prod_{i=1}^{|A|}{Pr(A_i = a_i | C =c_j)}
		$$
		* We compute the maximum probability given a test case, gives us the most probable class for a test case
	- First, compute prior probabilities $Pr(C = c_j)$ and $Pr(A_i = a_i | C = c_j)$
		- $Pr(C=c_j) = \frac{number\ of\ examples\ of\ class\ c_j}{total\ examples\ in\ the\ data\ set}$
		- $Pr(A=a_i | C=c_j) = \frac{number\ of\ examples\ with\ A_i=a_i\ and\ class\ c_j}{number\ of\ examples\ of\ class\ c_j}$
- Classify test instance
	- If we only need the most probable class for the test then the denominator doesn't matter
	- we can take the max of $Pr(c_j)$

	- Compute all probabilities required for classification
		- What is the probability for each class $c_j$?
			- If $C = t$? => $Pr(C=t) = \frac{1}{2}$ because half of values of $C$ are $t$.
			- If $C = f$? => $Pr(C = f) = \frac{1}{2}$ because of half of $C$ is $f$.
		- Now compute the probabilities for each attribute in $A$ and $B$ 
$$\begin{matrix}
Pr(A=m | C=t) = \frac{2}{5}, Pr(A=m | C=f) = \frac{1}{5}\\
Pr(B=b | C=t) = \frac{1}{5}, Pr(B=b | c=f) = \frac{2}{5}\\
Pr(A=g | C=t) = \frac{2}{5}, Pr(A=g | C=f) = \frac{2}{5}\\
Pr(B=s | C=t) = \frac{2}{5}, Pr(B=s | C=f) = \frac{1}{5}\\
Pr(A=h | C=t) = \frac{1}{5}, Pr(A=h | C=f) = \frac{2}{5}\\
Pr(B=q | C=t) = \frac{2}{5}, Pr(B=q | C=f) = \frac{2}{5}
\end{matrix}$$
* Now that we have the probabilities, we can compute the following example:
	* Given $A=m$, $B=q$, find $C=?$
	* For $C = t$, compute using the previous formulas:
		* $Pr(C=t)\prod_{j=1}^{2}{Pr(A_j=a_j | C=t)} = \frac{1}{2} * \frac{2}{5} * \frac{2}{5} = \frac{2}{25}$
	* For $C = f$, compute using the previous formulas:
		* $Pr(C=f)\prod_{j=1}^{2}{Pr(A_j=a_j | C=f)} = \frac{1}{2} * \frac{1}{5} * \frac{2}{5} = \frac{1}{25}$
	* So $C=t$ is the more probable class!
	  
- Additional issues
	- [[zero counts]] - an attribute value never occurs with a class in the training set, but shows up in testing, so we need (**smoothing**)
		- for every possible value, we have a small probability $\lambda$ 
		- We modify our formula to be$$
Pr(A_i = a_i | C = c_j) = \frac{n_{ij}+\lambda}{n_j + \lambda m_i}
$$
			* $n_j$ is the number of examples with $C=c_j$ in the training data
			* $n_{ij}$ is the number of examples with $A_i=a_i$ and $C=c_j$
			* $m_i$ is the number of possible values with attribute $A_i$
			* $\lambda$ is normally set to **1**
	- Numeric attributes
		- Naive Bayesian classifiers assume all attributes are **categorical**
		- Must be discretized
			- 2 strategies
				- 1) Don't care - chop into equal size bins
				- 2) We use entropy (:agony:)
		- We can use [[decision tree induction]]
	- **Ignore missing values**
		- We compute probabilities for every attribute
- Advantages of NB classifiers:
	- Easy implementation
	- very efficient
	- good results in many applications
- Disadvantages of NB classifiers
	- Assumes class conditional independence
		- significant loss of accuracy when this assumption is violated
		- e.g. in a game dataset (tic tac toe), decision tree and CBA gives 100% accuracy while NB only gives 70% (the game is deterministic, real datasets are not going to be deterministic)
