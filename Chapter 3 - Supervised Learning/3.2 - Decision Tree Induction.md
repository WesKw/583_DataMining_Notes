- [[Decision tree learning]]
	- Very widely used technique for classification
		- Efficient, competitive accuracy
	- Classification model is a [[decision tree]]
	  Example with loan data:
	- ![[Pasted image 20260226143423.png]]
		- Each leaf node is a class (yes/no)
		- Each question is a decision node
	- Decision trees are not unique given a set of data
	- We want trees to be as **small** and as **accurate** as possible - for understandability and performance
	- Best tree is an NP-Hard problem
	- Existing tree building algorithms are heuristic
		- speed over optimal
		- Experience-based, approximations
	- Decision trees can be converted to a set of [[association rule]]s
		- **Paths from the root to a leaf is a rule**
	- Algorithm
		- Greedy divide and conquer algorithm
			- Attributes can be categorical or continuous 
			- Top-down recursive manner of construction
			- all training examples are at the root
			- Attributes are selected through [[information gain]]
		- Conditions for stopping partitioning
			- All examples for a node belong to the same class
			- No remaining attributes - majority class is the leaf
			- no more examples
		- ![[Pasted image 20260226155938.png]]
			- 1, 2, 3 are partitions, split between each value of age
			- we recursively partition with further attributes
	- How do we choose an attribute to partition data?
		- We want to reduce impurity or uncertainty in data as much as possible
		- __pure__ - subset of data in which all instances belong to the same class
		- We choose attributes with maximum [[information gain]] or [[gain ratio]] through [[information theory]]
		- [[information theory]]
			- mathematical basis for measuring information content
			- We want to pay more for advanced information 
			- the less we know, the more valuable the information is 
			- Measures information contents in bits
			- We use entropy to measure impurity or disorder
				- formula: $\text{entropy}(D) = -\sum_{j=1}^{|C|}{Pr(c_j)log_2Pr(c_j)}$
				- $\sum_{j=1}^{|C|}{Pr(c_j)=1}$
				- Where $Pr(c_j)$ is the probability of class $c_j$ in $D$
				- measure of information in a tree
				- **As data becomes purer, the entropy value becomes smaller**
		- Given a set of examples $D$:
			- First, we compute the entropy of $D$ by applying the formula with each possible class
			- If we have an attribute $A_i$ with $v$ values, as root of the current tree, we partition $D$ into $v$ subsets $D_1, D_2, ..., D_v$
			- Entropy for $A_i$ as the root:
				- $\text{entropy}_{A_i}(D)=\sum_{j=1}^{v}\frac{|D_j|}{|D|}*\text{entropy}(D_j)$
			- Then to calculate information gain by selecting $A_i$:
				- $\text{gain}(D, A_i) = \text{entropy}(D) - \text{entropy}_{A_{i}}(D)$
				- In order to choose the best starting attribute, we must evaluate every attribute
	- How do we handle continuous attributes?
		- Split into 2 intervals at each node
		- Find best threshold by using information gain, sort all values of a continuous attribute in increasing order, find all possible cuts to maximize gain
	- [[Overfitting]]
		- Good accuracy on training data but poor on test data
		- Symptoms: deep decision tree, many branches
		- Approaches:
			- Pre-pruning to halt tree construction early
				- difficult to decide
			- Post-pruning: Remove branches or sub-trees from a fully grown tree
	- Other issues:
		- Trees to rules, rule pruning
		- Handling of missing values (we can insert values by using averages)
		- Handling skewed distributions
		- Attributes and classes w/ different costs
		- Attribute construction
	  
- Can handle missing values, and class in terms of cost 
- Can convert from trees to rules
- Can handle numerical and categorical data
	- **Many other algorithms cannot automatically deal with missing values or mixed attribute types**
- We can combine classifiers (combinations of trees) to build better classifiers
