- PageRank and HITS algos both reported in 1998
- PageRank and HITS have many connections
- PageRank is dominant
	- query-independence
	- Combats spamming
		- How does this work?
			- 1) Users can't control the number of in-links, but they can control out-links
			- 2) PageRank considers prestige of actors of the in-links
	- Responsible for Google's success
- Relies on the democratic nature of the web
- Interprets a hyperlink from page $x$ to page $y$ as a vote by $x$ for $y$
	- It also analyzes the pages that cast the votes
	- "Important" pages weigh more heavily to make other pages more "important"
		- This is the idea of [[Rank Prestige]]
- Algorithm
	- The importance of page $i$ is the sum of the rank scores of all pages that point to it
	- $$P(i) = \sum_{(j,i)\in E}{\frac{P(j)}{O_j}}$$
		- Where $O_j$ is the number of out-links of $j$
		- This becomes some kind of probability....
		- The web is a directed graph $G=(V,E)$
	- Matrix notation
		- We have $n$ linear equations w/ $n$ unknowns, so we can use a matrix
		- $P$ is an $n$-dimensional col vect...
- Solve the PageRank equation
	- $P=A^TP$
	- This is the characteristic equation of the eigensystem, where the solution to $P$ is an eigenvector w/ corresponding eigenvalue of 1
	- If some conditions are satisfied, 1 is the largest eigenvalue and $P$ is the principal eigenvector -> there is a solution
	- Power iterations can be used to find $P$
	- However, the Web graph does not meet the conditions to the equation does not work
- We can use a Markov chain to introduce conditions and the enhanced equation
	- In the Markov chain, a web page / node in the we graph is regarded as a state
	- Hyperlink is a state transition
	- Web surfing is modeled as a stochastic process
	- **Recall that Markov chains are stochastic processes, the next state only depends on the current state.**
		- Probability of $\beta$ only depends on the current state $\alpha$.
- Random surfing 
	- $O_i$ to denote the number of out-links of a node $i$
	- Transition probability is 1/$O_i$
	- Uniformly distributed and random
		- Back button is not used
		- surfer does not type in a URL
	- Then we get a state transition probability matrix $A$
		- $A_{ij}$ represents the transition probability that the surfer will move from state $i$ to $j$
	- Given an initial probability distribution vecotr
		- $p_0 = (p_0(1), p_0(2), ..., p_0(n))^T$ column vector, $n*n$ transition prb matrix $A$
		- sum of $p_0$ is 1, sum of $A_{ij}$ for all j
	- If the matrix $A$ satisfies the sum, we say $A$ is the stochastic matrix of a Markov chain
	- However, a web page does not satisfy this condition
		- Some web pages might not have any links
		- We will solve this problem later (called a dangling page)
	- Question of common interest: Given $p_0$, what is the probability that $m$ steps / transitions later the Markov chain will be at each state $j$?
	- We determine the probability that the random surfer is in state $j$ after 1 step$$p_1(j)=\sum_{i=1}^{n}A_{ij}(1)p_0(i)$$
		- $A_{ij}(1)$ is the probability of going form i to j after 1 transition, $p_1=A^Tp_0$
		- What about k steps?
		- $p_k = A^Tp_{k-1}$?
		- A finite Markov chain, defined by stochastic matrix A has a unique stationary probability distribution of $A$ is is **irreducible** and **aperiodic**
		- stationary probability distribution - after a series of transitions $p_k$, will converge to a steady state probability vector $\pi$ 
		- steady state: $p_k=p_{k+1}=\pi=P$
			- this $\pi=A^T\pi$
			- $\pi$ is the principal eigenvector
		- From every page, we must be able to get out we can't get stuck
	- Is $P=\pi$ justified?
		- Reflects long-run probabilities of random surfer visiting pages
		- Page has high [[Prestige]] if probability of visiting it is high
- Back to the web graph
	- 3 conditions:
		- 1) A is a stochastic matrix
		- 2) A is irreducible
		- 3) A is aperiodic
	- None of these conditions are satisfied
	- How do we deal with this?
	- For condition 1: We can randomly type a link, or create a small link to every page, or remove any dangling pages
	- $A$ is not irreducible
		- Web graph $G$ is strongly connected - from every node, we can get to every other node.
	- $A$ is not aperiodic
		- There exists a directed cycle that the chain has to traverse
		- This is an issue, it's not stationary if the location depends on the step number
		- periodic w/ period $k > 1$ if $k$ is the smallest number such that all 
		- We do not want periodic matrix
	- How do we get conditions 2 and 3?
		- 2 kinds of links: 1 original link, 1 artificially added link
		- Probability $d$ -> randomly chose and out-link
		- Probability $d-1$ -> jump to a random page
		- Improved equation: $$P=((1-d)\frac{E}{n}+dA^T)P$$
		- $E$ is $ee^T$, e is column vector of all 1s, so $E$ is an $n*n$ square matrix of 1s
	- Final algorithm:
		- Scale eq so $e^TP=n$
		- $P(i)=(1-d)+d\sum_{(j,i)\in E}{O_j}/n$???
		- $d$ is called **damping**
	- Advantages:
		- fighting spam
			- not easy to influence page rank
		- Global measure and query independent
			- Saves all pages that are computed and saved offline rather than at query time
	- Criticism:
		- Query-independence - can't distinguish  b/w pages that are authoritative in general and authoritative on the query topic.
