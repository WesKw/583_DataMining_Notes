- ## How to use unlabeled data
	- [[EM Algorithm]]
		- Expectation maximization
		- Iterative algorithm for maximum likelihood estimation in problems w/ missing data
		- 2 steps:
			- **Expectation step** - fill in the missing data
			- **Maximization step** - calculate a new maximum *a posteriori* estimate for the parameters
			- Essentially, we estimate missing data, then we build another classifier.
			- Mathematically proven to converge - but it does not converge to the optimum
				- Same thing as a local classifier
		- **Basic EM**
		- **Augmented EM w/ weighted and unlabeled data**
		- **Augmented EM w/ multiple mixture components per class**
		- Algorithm outline
			- Learn initial naive bayesian classifier from labeled set L
			- We use the classifier to compute the probabilities of missing data
			- learn a new classifier based on the new set of probabilities
			- Repeat until the classifier parameters stabilize
		- basically, run naive bayes until it converges
			- Does not find a global minimum, only local
		- Experimental evaluation
			- Newsgroup postings - 20 newsgroups, 1000/group
			- Web page classification
		- This algorithm has many problems
			- Only works well if:
				- data is generated a mixture model
				- one-to-one correspondence b/w mixture components and document classes
			- Does not give a global minimum
			- A class may contain a number of sub-classes
				- Remember from [[3.7 - Naive Bayesian Text Classification]], if we lump lots of classes into one class (combining multiple generators into one), it's very bad!
					- E.g. we need to make sure that the class distribution is one-to-one correspondent
					- if we know our data well, this is pretty easy to avoid
					- To deal with this, we can automatically identify classes via [[cluster]]ing! This works *to some extent*, but remember that clustering is very unreliable
					- Possible to solve manually, automatically is much harder
						- But in practice, manually is very difficult - we need to label more data!
	- [[Co-training]]
		- Learning with a small labeled set and large unlabeled set
		- Partition attributes describing each example into 2 subsets
		- Split data into parts, we assume each part is able to solve the problem reasonably well
		- Algorithm: ($L$ is labeled data, $U$ is unlabeled data)
			- 1) Repeat:
				- Learn classifier $f_1$ using L based on only $x_1$ portion of the examples $x$
				- Learn classifier $f_2$ using L based on only $x_2$ portion of the examples $x$
				- Apply $f_1$ to classify examples in $U$, for each class $c_i$, pick $n_i$ examples that $f_1$ most confidently classifies as class $c_i$ and add them to $L$
				- Apply $f_2$ to classify examples in $U$, for each class $c_i$, pick $n_i$ examples that $f_2$ most confidently classifies as class $c_i$ and add them to $L$
			- Repeat until $U$ becomes empty or a fixed number of iterations have been reached
		- $f_1$ adds examples to the labeled set that is used for learning $f_2$ based on $x_2$ and vice versa
		- This algorithm can become very biased if we only have 1 classifier (this is called self-learning)
		- If we do random sampling, we can learn the whole space (this is what the classifiers solve)
		- Co-training solves the problem of self learning
	- Semi-supervised learning does not help much when a large # of training data is available
		- This is kind of the reason why it's not used very much in practice...
