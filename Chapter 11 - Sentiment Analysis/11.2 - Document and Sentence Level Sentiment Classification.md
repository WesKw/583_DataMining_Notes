- Classify a whole opinion document based on overall sentiment
- Classes: **Positive, Negative, (Possibly neutral)**
	- Defining neutral is very hard
- Basically a [[Text classification]] problem
- ## Sentence sentiment analysis
	- Classify the sentiment expressed in a sentence
		- Classes: positive, negative, neutral
		- neutral - no sentiment expressed, objective sentence
		- positive & negative - subjective sentence
	- Bear in mind different kind of [[Regular Opinion]]s:
		- Explicit opinion: "I like this car"
		- Fact-implied opinion: "I bought this car yesterday and it broke today"
		- Mixed opinion: "Apple is doing well in this poor economy"
	- We can't really consider mixed opinions - we need to go to the aspect-based (apple is positive, economy negative)
- Classification approaches:
	- [[Supervised]] learning methods - class reviews into positive and negative
		- [[3.6 - Naive Bayesian Classification]], [[information gain]], [[3.8 - Support Vector Machines]]
		- Also deep learning
	- [[Unsupervised]] methods
		- Lexicon-based methods
			- sentiment words & phrases (good, wonderful, cost an arm and a leg, troublesome)
		- We need these too because we don't always have labeled data.
- [[Supervised]]
	- Key: feature engineering
