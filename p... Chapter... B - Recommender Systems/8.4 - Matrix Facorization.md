- Looks for *hidden* information, as opposed to the previous techniques
	- What's the underlying reason that a movie was given a 5 star rating?
- Decompose matrix $M$ into the product of several factor matrices, i.e.
	- $M=F_1F_2...F_n$ 
	- $n$ can be any number, usually 2 or 3.
	- Not the traditional mathematical single value decomposition
- Gained popularity for [[B.3 - Collaborative Filtering]] in recent years due to its superior performance in terms of recommendation quality and scalability
- Netflix Prize contest
	- popularized a SVD based matrix factorization algorithm
	- _Training data_: quadruples of the form (user, movie, rating, time)
	- _Testing_: predict the rating of each triplet
	  
## Abstract Idea
- Latent factor model
- __Latent variables__ (features, aspects, factors)
	- Account for the underlying reasons of a user purchasing a product

## SVD Factorization
- Technique given by Simon Funk, derivation described by Wagman
- Method was later improved by Koren et al and several other researchers

## Intuition
- Imagine that there are hidden or latent aspects that people use to give ratings to movies
- Most, if not all, of these should be explainable by these hidden aspects or attributes
- We then use a linear combination of them to produce rating predictions
- If we can use training data w/ ratings to discover latent aspects, user-aspects, movie-aspects relationships, we can use them to predict the user ratings of movies that they have not rated
- Remember: columns are users, rows are aspects

## Simon Funk's SVD method
- Diagonal scaling matrix is not used here
- user-movie-rating data matrix $R$, w/ 8.5 billion cells
	- nonempty cell $r_{ij}$ rating of user $i$ on movie $j$
	- each user is a column
	- SVD decomposes $R$ into 2 matrices, $U$ user-aspect, and $M$ movie-aspect matrices
- Use $K=90$ latent aspects (needs to be set experimentally)
- Each user and movie described by only ninety aspect values
- To combine these into a rating, we multiply each user pref by the corresponding movie aspect, then sum them up to predict a rating
- $$r_{ij}\approx u_i^Tm_j=\sum_{k=1}^{K}{u_{ki}\times m_{kj}}$$
- SVD minimizes the resulting approximation error, the **mean squared error** (MSE)
- We can use $U$ and $M$ to predict the ratings in the test set.

- To minimize error, we use [[gradient descent]]
	- Take partial derivative of the squared error
- Error: $e_{ij}$
	- $e_{ij}=r_{ij}-p_{ij}$
